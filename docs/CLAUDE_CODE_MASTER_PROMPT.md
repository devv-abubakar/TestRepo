## 0. Your role and working rules

You are the sole developer of **SHATTERFLUX**, a premium neon brick-breaker (arcade) game for Android, built **100% in Kotlin**. The product owner will not write code. You write, build, test, and polish everything, end to end, until it is Play-Store-ready.

Working rules:
1. **Be autonomous.** Do not ask questions you can answer yourself. Make the best decision, note it in `docs/DECISIONS.md`, and continue.
2. **Work in phases** (section 12). After each phase: build, run unit tests, run lint, fix everything, then `git commit` with a clear message. Never leave the build broken.
3. **Install what you need.** If the Android SDK / cmdline-tools / build-tools / platform are missing, install them (sdkmanager). If a CLI tool is missing (ImageMagick, rsvg-convert, Inkscape, Node + Playwright, ffmpeg), install it or use an equivalent. Verify with real commands; never claim something works without running it.
4. **No paid or copyrighted assets.** Everything is drawn in code, generated by script, or CC0 (credit in `docs/LICENSES.md`). No third-party game names, logos, or sounds.
5. **Verify on an emulator when possible** (create an AVD, run `connectedAndroidTest` or at least install & launch and take screenshots). If an emulator is impossible in this environment, say so clearly in the final report and rely on unit tests + Robolectric/lint instead. Never invent test results.
6. Keep code clean, documented where non-obvious, and consistent in style. Prefer small, focused files.
7. At the end, give an honest report: what works, what is verified, what the owner must do manually.

## 3. Core gameplay

Classic loop: paddle at bottom, ball(s), bricks above. Player drags to move the paddle; tap to launch / use action. Lose a ball if it passes the paddle; lose all lives = game over (with continue offer).

Required feel:
- Precise **continuous collision** (swept circle-vs-AABB, sub-stepping) — no tunnelling at high speeds, no sticking, no ball-stuck-in-brick bugs.
- Paddle hit angle depends on impact position; add anti-horizontal-lock (minimum vertical speed) and a gentle speed ramp per level, capped.
- Input latency as low as possible; paddle follows finger with slight smoothing, optional "relative drag" vs "absolute follow" setting.
- Pause on app background; resume safely; handle rotation lock, process death, and screen-off.

### Brick types
Normal (1 hit), Strong (2–4 hits, cracks visibly), Armored (needs fire/explosive), Unbreakable, Explosive (area), Moving (slides), Regenerating, Ghost (appears/disappears), Chain-lightning, Gift (drops guaranteed power-up), Boss-weakpoint.

### Power-ups (capsules fall; catch with paddle)
Multi-ball, Wide paddle, Narrow-trap (negative, rare), Fireball, Mega-ball, Laser, Magnet/Catch, Slow-motion, Shield (one-time floor), Extra life, Gravity-well, Score x2, Chain-lightning, Freeze-time. Timers shown as chips (see mockup). Balanced drop rates; some power-ups can level up when collected repeatedly in a run.

### Combo and scoring
Combo multiplier for consecutive brick hits without touching the paddle; perfect-paddle-hit bonus; on-screen combo text; per-level star rating (1–3) and run score.

## 4. Infinite levels (the heart of the game)

Levels never end and never feel repetitive. Implement a **deterministic procedural generator** `LevelGenerator(seed = f(levelIndex, worldSeed))`:
- Pattern library: symmetric shapes (hearts, diamonds, spirals, waves, pyramids, letters/digits, checker, rings, mazes, invader-style sprites, cellular-automata, noise fields), mirrored/rotated/mixed. Add a validator: every level is **solvable** (no unreachable required bricks, enough breakable bricks, no ball-trap pockets) and **fair**.
- Difficulty curve over level index: brick HP, density, unbreakable/moving brick share, ball speed, power-up generosity. Smooth, with periodic "breather" levels and every-5th "special" level (e.g. timed, no-power-up, boss-rush mini, bonus coin room).
- **Boss every 10 levels** with multiple phases, attack patterns (projectiles the paddle must dodge), weak points, unique visual per boss; bosses scale infinitely.
- **Worlds / themes** change every 25 levels (new palette, background, particle style, music mood): Neon City, Void Nebula, Crystal Cave, Solar Forge, Glitch Matrix, Deep Ocean, Aurora… then cycle with remixed palettes. Provide at least 8 distinct themes.
- Modifiers that rotate in ("Low gravity", "Mirror paddle", "Darkness with light cone", "Speed surge", "Brick rain") so each level can feel different.
- Level index shown in HUD; "Endless" is the main mode. Also: **Daily Challenge** (seed by date), and **Classic Stages** (first 100 hand-tuned via generator presets). Seeds are testable and reproducible.
- Unit-test the generator: determinism, solvability, difficulty monotonicity, no crashes for level 1…100000.

## 5. Meta-progression (keeps players coming back)

- Soft currency (**Shards**) earned in play; **no real-money purchases in v1**.
- Unlockables via shards: paddle skins, ball skins/trails, brick styles, background themes, particle packs (all code-generated visuals).
- Achievements (~40) and Daily Missions, daily login reward, streaks.
- Statistics screen: best level, total bricks, longest combo, play time.
- Local save with **DataStore** (versioned, migration-safe, corruption-tolerant). Optional export/import of progress as a text code.
- Rate-us prompt shown at a good moment (after a high score), never during gameplay, rate-limited.

## 6. Screens and UX (Compose, Material 3, fully custom neon style)

Splash → Home (animated title, Play / Endless level, Daily, Skins, Missions, Settings) → Game → Pause → Game Over / Level Complete (stars, score count-up, rewards) → Skins/Shop → Achievements → Stats → Settings (sound, music, haptics, control sensitivity, graphics quality: Auto/Low/Medium/High, 60/90/120 FPS, left-hand mode, colour-blind palettes, reduce motion, language) → Privacy/About.
- Design language: dark base, glassmorphism pills, gradient neon accents, big readable typography, 48 dp+ touch targets, smooth shared-element-like transitions, spring animations, haptic taps.
- Accessibility: TalkBack labels on menus, colour-blind safe palette option, adjustable UI scale, reduce-motion switch.
- Localisation scaffold with `strings.xml`: English (default), Urdu, Hindi, Arabic, Spanish, Portuguese, Indonesian, Turkish (RTL support correct).
- Tutorial: first run shows a 20-second interactive hint (drag to move, tap to launch), no walls of text.

## 7. Graphics (rich but cheap)

All visuals procedural / vector in code — **zero bitmap game assets** beyond the launcher icon:
- Bricks: rounded rect + gradient + gloss + glow (pre-rendered to cached bitmaps/Pictures per colour & size, not re-computed per frame).
- Ball: glow + motion trail (ring buffer), fireball/mega variants.
- Particles: pooled structure-of-arrays, hard caps, no allocation in the game loop.
- Background: parallax star/nebula/grid layers per world, drawn from cached bitmaps; subtle animated shader-like effects done cheaply.
- Screen shake, hit-flash, chromatic pop on big combos, slow-mo on boss kills, lightning/laser beams, shockwave rings (see mockup + prototype).
- **Adaptive quality manager:** measure frame time; if p95 > budget, automatically reduce particle caps, glow, trail length, background layers; restore when stable. Quality tiers: Low (no glow, 150 particles, 1 bg layer), Medium, High. Auto picks tier from RAM/class/SoC and live frame stats.

## 8. Audio and haptics

- Generate all SFX **procedurally at build/first-run** (synthesized WAV via code: pitch-shifting hit sounds by combo, laser, explosion, power-up, UI taps) and play via `SoundPool`; low latency. Optional music: short procedural loops (generated by script into compressed assets) per world, or CC0 tracks with licences listed. Volume ducking, mute switches, respect system silent mode, pause audio on background.
- Haptics: light tick on brick hit, stronger on power-up/explosion, with a settings toggle (use `VibrationEffect`, guard for API levels).

## 9. Performance and robustness (non-negotiable)

- Target: **stable 60 FPS on a 2 GB RAM / low-end quad-core device**, cold start < 2 s, APK/AAB small (target < 15 MB download), idle RAM small, no jank.
- **Zero allocations in the per-frame loop** (verify with allocation profiling or code review): pooled objects, primitive arrays, reused Paint/Path/Matrix, no lambdas/boxing in hot paths.
- Fixed timestep physics (e.g. 120 Hz sub-steps) decoupled from render; interpolation for smoothness; deterministic simulation given the same seed + inputs.
- Spatial grid for brick collision; cap simultaneous balls/particles/projectiles.
- Battery-aware: pause loop when not visible; avoid wake locks; cap FPS in battery saver.
- Crash-safe: never crash on bad saved data; global exception handler writes a local log; strict null-safety.
- Enable **R8 minify + resource shrinking** for release; add Baseline Profile if feasible; test release build, not just debug.
- Memory: no leaks (SurfaceView lifecycle, DataStore, SoundPool released properly).
